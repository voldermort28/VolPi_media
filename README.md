# Stremio Addons Server (VLXX & Xôi Lạc TV)

Server cung cấp Addon cho Stremio được tách biệt hoàn toàn theo nhu cầu sử dụng.

---

## 🔗 Danh sách Addon Link

### 1. Addon Xôi Lạc TV (Chỉ xem Trực Tiếp Bóng Đá)
- **Manifest URL**: `https://stremio.laboon.vn/xoilac/manifest.json`
- **1-Click Install**: `stremio://stremio.laboon.vn/xoilac/manifest.json`
- **Tính năng**:
  - Xem trực tiếp tất cả các trận đấu bóng đá (Ngoại Hạng Anh, C1, La Liga, Serie A, V-League, World Cup...).
  - Đầy đủ các kênh BLV Tiếng Việt (Kênh #1, #2, #3, #4...).
  - Mục **Discover -> TV Streams -> Trực Tiếp Bóng Đá (Xôi Lạc)**.

---

### 2. Addon VLXX (Chỉ xem Phim)
- **Manifest URL**: `https://stremio.laboon.vn/vlxx/manifest.json`
- **1-Click Install**: `stremio://stremio.laboon.vn/vlxx/manifest.json`
- **Tính năng**:
  - Tìm kiếm theo mã phim (code JAV) hoặc từ khóa.
  - Luồng HLS mượt mà đã loại bỏ 100% quảng cáo pop-up.
  - Mục **Discover -> Movies -> VLXX Mới Cập Nhật**.

---

### 3. Addon Tổng Hợp (Cả Phim & Bóng Đá trong 1 Addon)
- **Manifest URL**: `https://stremio.laboon.vn/manifest.json`
- **1-Click Install**: `stremio://stremio.laboon.vn/manifest.json`
