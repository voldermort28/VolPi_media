Cấu Hình Telegram App API (my.telegram.org)

📋 Cách tạo API ID & API Hash chính chủ miễn phí:

  1. Truy cập my.telegram.org và đăng nhập bằng số điện thoại Telegram của bạn.
  2. Chọn mục API development tools.
  3. Điền App title (ví dụ: VolPi Media) và Short name (ví dụ: volpi), rồi bấm Create application.
  4. Sao chép App api_id và App api_hash dán vào 2 ô bên dưới và nhấn Lưu Cấu Hình API.

💡 Lưu ý: Telegram đã chặn hoàn toàn các API ID mẫu công khai cũ (mã 2496). Bạn bắt buộc cần lấy api_id & api_hash chính chủ từ my.telegram.org để tránh lỗi 400 API_ID_INVALID.
