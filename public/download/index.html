Cài trên Android TV

Mở ứng dụng Downloader trên TV, nhập link rút gọn hoặc quét mã QR để tải và cài đặt trực tiếp file APK.

Cài trên iPhone / iPad

Mở Safari trên iPhone, bấm "Cài Nhanh qua TrollStore" để ứng dụng tự động nạp và cài đặt vĩnh viễn.

Cài trên macOS

Tải file .zip, giải nén và kéo file volpi_media.app vào thư mục Applications để mở sử dụng.

Cập nhật tự động

Sau khi cài đặt lần đầu, ứng dụng sẽ tự động thông báo khi có bản mới để bạn cập nhật nhanh chóng.
